# CEB Energy Saver - Concept Web App

A browser-based electricity management application focused on reducing household electricity wastage.

## Features
- Live household power overview
- Appliance monitoring and on/off controls
- Add, search, filter, schedule and remove appliances
- Daily and weekly usage analytics
- Wastage and high-consumption alerts
- Monthly energy-saving goals
- Energy-saving recommendations and tips
- Electricity bill estimator
- Dark mode and responsive mobile layout
- Browser localStorage persistence

## Run
### Easiest method
Open `index.html` in Chrome, Edge, Firefox or Safari.

### Recommended local server
If Python is installed, open a terminal in this folder and run:

```bash
python -m http.server 8000
```

Then open: `http://localhost:8000`

## Notes
This is a concept/demo application and is not an official product of the Ceylon Electricity Board. It uses sample data and does not connect to a real smart meter or CEB billing system.
